# 相続税申告 初回面談支援ツール

相続税申告・相続手続きを行う事務所の職員が、お客様との初回面談時に **iPad（ブラウザ）で** その場で使うためのツールです。

- サーバー・アプリのインストールは不要です。このフォルダを開くだけで動作します。
- 入力したデータは **その端末のブラウザ内（localStorage）にのみ** 保存されます。外部のサーバーへは一切送信されません。
- 郵便番号検索のみ、このツールに同梱した住所データファイル（`data/postal-codes.json`）を読み込みますが、これは同じ場所（同一オリジン）に置かれた静的ファイルであり、外部・第三者のサーバーとは一切通信しません。
- 別の端末や職員間でデータを共有したい場合は、「JSON書き出し」でファイルを保存し、共有・読込してください。

## できること

1. **案件管理**：お客様（被相続人）ごとに案件を作成・保存・複製・削除。
2. **基本情報**：被相続人の氏名・生年月日・死亡日などを入力すると、相続税申告期限（死亡日の翌日から10か月）を自動表示。郵便番号を入力して「住所検索」を押すと住所を自動入力。
3. **面談記録**：面談概要、遺言・生前贈与・保険金・不動産等のヒアリング項目、必要書類チェックリスト、面談メモを記録。対応者(事務所側)はあらかじめ登録した職員からプルダウンで選択（「職員管理」ボタンから追加・削除）。
4. **相関図・相続人**：続柄を選ぶだけで世代ごとに自動配置される相続関係図を作成。法定相続人・法定相続分・遺産に係る基礎控除額を自動計算（あくまで面談時の目安。最終判断は必ず税理士が行ってください）。
5. **財産目録**：土地・建物・現金預金・有価証券・保険金・債務・葬式費用等の概算額を分類ごとに入力し、自動集計。基礎控除額との比較も表示。土地は利用区分（自用地・貸地・貸家建付地・使用貸借・月極駐車場）、家屋は利用区分（自用家屋・貸家・使用貸借）を選択可能。生命保険金の受取人は相関図で登録した相続人からプルダウンで選択可能（自由入力も可）。
6. **出力**：画面印刷／PDF保存（面談記録シートとして1枚にまとめて印刷可）、財産目録・相続人一覧のExcel(.xlsx)書き出し、案件データのJSONバックアップ・復元。

## 使い方（iPad）

1. このフォルダをWebサーバー（例：GitHub Pages）で公開し、Safariでアクセスします。
2. ホーム画面に追加すると、アプリのように起動できます（共有ボタン →「ホーム画面に追加」）。
3. 面談前に「＋ 新規案件」でお客様の案件を作成し、面談をしながら各タブに入力してください。
4. 面談終了後、「概要・印刷」タブから印刷／PDF保存、Excel書き出しができます。

## 開発者向けメモ

- 純粋なHTML/CSS/JavaScriptのみで構成（外部ライブラリ・CDN依存なし、オフラインで完結）。
- `index.html` … 画面構造 / `style.css` … スタイル（印刷用スタイルは `@media print` に定義）/ `app.js` … ロジック一式 / `data/postal-codes.json` … 郵便番号→住所の変換用データ（同梱・同一オリジン読込のみ）。
- Excel出力は、外部ライブラリを使わずZIP(格納・無圧縮)を直接組み立てて正規のOffice Open XML(拡張子 `.xlsx`)を生成しています。
- 職員名簿（対応者プルダウン用）は案件データとは別に、端末のlocalStorageに保存しています（全案件で共通）。
- 法定相続人・法定相続分・基礎控除の計算は簡易ロジックです。代襲相続の発生有無はユーザーが「孫（代襲相続人）」「甥・姪（代襲相続人）」として明示的に登録する前提とし、半血兄弟姉妹の相続分調整などは行っていません。
